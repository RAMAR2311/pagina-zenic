# Cerebro de Zenic: Guía de Uso para Asistentes y Agentes

Este repositorio constituye la base de conocimiento oficial y centralizada de ZENIC S.A.S.  
Fecha: 11 de noviembre de 2026

---

## 1. Propósito de este repositorio
Este repositorio (`zenic-cerebro`) es el cerebro corporativo de ZENIC S.A.S. Cualquier modelo de lenguaje, asistente de IA (Claude, Antigravity u otros) o miembro del equipo debe consultar estos archivos antes de responder, redactar o tomar decisiones relacionadas con la empresa, sus productos o sus clientes.

## 2. Regla Fundamental: Cero Invención de Datos
- **Nunca inventes información.** Si un dato, precio, cifra, cliente, integración o capacidad técnica no se encuentra documentado explícitamente en estos archivos, responde que la información no está disponible.
- Si detectas vacíos de información durante la operación o redacción, marca la sección con `[POR COMPLETAR]` y regístrala de inmediato en `pendientes.md`.

## 3. Principios de Operación
1. **Consultar primero:** Antes de responder cualquier duda sobre Zenic, revisa la carpeta temática correspondiente (`empresa/`, `producto/`, `clientes/`, `ventas/`, `tecnico/`, `web/`, `decisiones/`).
2. **Tono de marca oficial:** Siempre mantén un tono cercano, directo y centrado en el "comercio real" colombiano.
3. **Privacidad estricta:** Este repositorio jamás debe contener contraseñas, credenciales de acceso, claves de API ni datos personales o privados de clientes.
4. **Mantenimiento vivo:** Cualquier cambio aprobado sobre la empresa o el producto debe actualizarse en estos archivos mediante control de versiones.
